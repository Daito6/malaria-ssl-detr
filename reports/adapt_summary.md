## 1. Протокол (коротко)

- Схема: бокси A (NMS 0.5) + лінійний класифікатор на замороженому енкодері, навчений на чистих train GT-кропах BBBC041;
  скор = objectness × p(infected). Мітки цілі читає лише підрахунок метрик.
- ДІ: 95 %, 1000 парних ресемплів, seed 42; NIH: **bootstrap по пацієнтах** (усі зображення витягнутого пацієнта),
  BBBC041: по зображеннях. Парні різниці рахуються на тих самих ресемплах.
- Поріг: `none` — max F1 на **чистому BBBC041 val** (це "поріг з BBBC-val"); `none_stainthr` — max F1 на stain-shifted val
  (контроль); `+em` / `+bbse` — поріг за квантилем: позитивними стає частка π̂ клітин, тож π̂ дорівнює частці клітин,
  названих infected (`pi_hat` = `pred_pos_frac_cells` в `_info.csv`).
- `adabn` вирівнює середнє / std ознак цілі; `em` — EM-оцінка апріорної частки infected, `bbse` — оцінка через
  матрицю плутанини на чистому val. Обидва потім перезважують постеріор.
- `par_img_bias` = середня (оцінена − справжня) паразитемія на зображення; `par_img_mae` — середня абсолютна похибка.
  Справжня частка infected клітин (`true_cell_pi`): NIH **0.0405**, BBBC041 test 0.0512.

- **Без AdaBN EM на NIH майже повністю "схлопується":** π̂ = 0.0004–0.0026, тобто в 16–100 разів менше за справжню

- Отже, жоден спосіб оцінки π не є точним на обох цілях для одного й того самого енкодера.

**Повторюється на обох цілях:** зміна робочої точки. Recall зростає, а від'ємний зсув паразитемії зменшується в усіх
парах обох цілей; precision падає скрізь, крім dino на BBBC041. Величина ефекту залежить від енкодера в однаковому
порядку на обох цілях: найбільший у b1, найменший у dino.

**Не повторюється:**
- **AP50.** На NIH AP50 ніде не зростає: b1 без змін, b2 і dino падають. На BBBC041 test, навпаки, dino і ImageNet
  ростуть, а всі SSL v2 падають. Для dino знак ефекту на двох цілях протилежний (NIH −0.061 / −0.077, BBBC041 `a_3s`
  +0.021).
- **MAE паразитемії.** На NIH він зменшується в 6/6 парах, на BBBC041 test лише для b2 і ref_imagenet. Для b1 і dino
  ДІ там містять 0, хоча зсув теж іде до нуля.
- **Оцінка π.** Точна лише для b1 на NIH; той самий метод для b1 на BBBC041 переоцінює (0.058–0.061 при 0.0512).
- **Між двома SSL-seed** (b1 і b2) на NIH ефект сильно розходиться: recall +0.46…+0.47 проти +0.22…+0.23, π̂ 0.040
  проти 0.014, `crop_auprc` +0.03 проти −0.02. Отже, величина ефекту залежить від seed SSL-передтренування, а не лише від
  методу.
- **Між бокс-запусками** (A42 / A43) знаки збігаються в усіх 6 парах NIH для AP50, recall, precision, bias і MAE. Розкид
  між боксами значно менший, ніж між енкодерами чи SSL-seed.

## 7. Висновки (EXPLORATORY)

- **SSL v2 краще за DINO на NIH, і це не залежить від адаптації.** b1 − dino AP50 +0.133…+0.140, b2 − dino
  +0.151…+0.166 при `none`; +0.181…+0.231 при `adabn+em`. Усі ДІ (bootstrap по пацієнтах) без 0 в обох бокс-запусках.
  Recall при порозі з BBBC041 val при цьому не кращий (b2 − dino −0.024 / −0.044).
- **Основна проблема NIH — поріг, а не ранжування:** при порозі з BBBC041 val recall 0.07–0.13 при precision 0.78–0.92,
  паразитемію занижено на ~0.04.
- **AdaBN + EM виправляє робочу точку, але не ранжування.** Recall зростає, а зсув паразитемії зменшується в усіх 24
  парах обох цілей. Ціна — precision, а AP50 не зростає на NIH і падає для SSL v2 на BBBC041 test. EM без AdaBN на NIH
  непридатний (π̂ ≤ 0.0026 при 0.0405).
- Найкращий результат за паразитемією на NIH — b1 + adabn+em: bias +0.004 / −0.000 (ДІ містять 0), MAE 0.026 / 0.024
  проти 0.040 / 0.042 у `none`. Але для b2 той самий метод дає MAE 0.030 / 0.032, тож це не стабільна властивість SSL v2.

Обмеження: NIH — лише 6 із 18 пар, немає `a_3s` і ref_imagenet / cont; по 2 SSL-seed на енкодер; на BBBC041 test немає
парних різниць енкодерів для методів адаптації; test BBBC041 багаторазово переглядався у фазах 4–7; поправки на
множинність немає (17 пар методів × 3 енкодери × 2 запуски × 11 метрик лише на NIH). `+em` / `+bbse` / `adabn`
трансдуктивні: потрібна партія немічених знімків нового домену.
